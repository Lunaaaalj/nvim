# Molten / notebooks

The notebook guide lives in the in-editor help, which is the only copy kept up
to date: `:help nvim-notebooks` ([`doc/nvim-notebooks.txt`](../doc/nvim-notebooks.txt)).

It covers how a buffer gets its kernel (automatic, from the project's venv;
no registration), the run keys, plots, troubleshooting, and R / Quarto.
